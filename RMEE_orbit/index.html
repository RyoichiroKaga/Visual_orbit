変換の入力

COE から Modified Equinoctial Elements（MEE）へ変換します。

COE 入力

α = [ p, L, f, g, h, k ]T

p = a(1 − e²) [km]

L = Ω + ω + M（平均経度）

f = e cos(Ω + ω)

g = e sin(Ω + ω)

h = tan(i/2) cos Ω

k = tan(i/2) sin Ω

MEE を直接入力し、古典軌道要素 COE へ逆変換します。

変換結果

MEE α = [ p, L, f, g, h, k ]

    COE（MEE から逆変換）

      RMEE の定義

      δα = αd − αc。 第1成分のみ δp/pc と正規化します。

      δα = [ δp/pc, δL, δf, δg, δh, δk ]T

      δp/pc = (pd − pc) / pc

      δL = Ld − Lc

      δf = fd − fc

      δg = gd − gc

      δh = hd − hc

      δk = kd − kc
