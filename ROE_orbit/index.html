Chief 軌道（COE）

ECI 表示と COE→ROE 変換の基準。サンプルは引数緯度 u = ω + ν を 0 → 2π で走査します。

相対軌道の入力

線形近似で a·δ に対応するスケール。スライダーは km、内部で δ = 値/a に変換します。

変換後 ROE（a·δ）[km]

  • a·δa … 1 km
  • a·δλ … 100 km
  • a·δex … 10 km
  • a·δey … 0 km
  • a·δix … 30 km
  • a·δiy … 0 km

軌道表示

δλ(t) = δλ0 − (3/2)n·δa·t を常に適用（Δa = 0 のときは各周が閉曲線に重なります）。

5

使用する近似式

近円軌道・小さい相対運動を仮定した線形近似。

R = a (δa − δex cos u − δey sin u)

T = a (δλ + 2 δex sin u − 2 δey cos u)

N = a (δix sin u − δiy cos u)

δλ(t) = δλ0 − (3/2) n δa t

  • R — Radial [km]
  • T — Along-track [km]
  • N — Cross-track [km]

ECI 誇張: r表示 = rchief + k(rdeputy − rchief) （k は表示専用）。地球は赤道面内に R⊕ ≈ 6378 km の円（実スケール）を表示。
